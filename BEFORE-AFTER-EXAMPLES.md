# Before & After: JSS to Emotion Migration Examples

This document shows real-world examples of how the updated utility transforms JSS code to Emotion, following the patterns from `img-tile-preview-graph.js` and `img-multi-tabs-component.js`.

## Example 1: Simple Container with Text

### Before (JSS)

```javascript
import React from 'react';
import { makeStyles } from '@mui/styles';
import { Box, Typography } from '@mui/material';

const useStyles = makeStyles({
  container: {
    paddingLeft: '15px',
    marginTop: '6px',
    display: 'inline-flex',
    minHeight: '80px',
    width: '100%',
  },
  title: {
    fontFamily: 'Roboto',
    fontSize: '14px',
    fontWeight: '500',
    color: '#6e6e6e',
    paddingTop: '10px',
  },
});

const MyComponent = () => {
  const classes = useStyles();

  return (
    <Box className={classes.container}>
      <Typography className={classes.title}>
        Hello World
      </Typography>
    </Box>
  );
};
```

### After (Emotion) - Generated by Utility

```javascript
import React from 'react';
import { styled } from '@mui/material/styles';
import { Box, Typography } from '@mui/material';

const StyledBox = styled(Box)({
  paddingLeft: '15px',
  marginTop: '6px',
  display: 'inline-flex',
  minHeight: '80px',
  width: '100%',
});

const TitleText = styled(Typography)({
  fontFamily: 'Roboto',
  fontSize: '14px',
  fontWeight: '500',
  color: '#6e6e6e',
  paddingTop: '10px',
});

const MyComponent = () => {
  return (
    <StyledBox>
      <TitleText>
        Hello World
      </TitleText>
    </StyledBox>
  );
};
```

**Changes:**
- ✅ `useStyles` removed
- ✅ `makeStyles` replaced with `styled`
- ✅ `container` → `StyledBox` (semantic name)
- ✅ `title` → `TitleText` (indicates Typography)
- ✅ JSX elements replaced with styled components
- ✅ `className` props removed

## Example 2: Dynamic Styles with Props

### Before (JSS)

```javascript
import React from 'react';
import { makeStyles } from '@mui/styles';
import { Button } from '@mui/material';

const useStyles = makeStyles({
  button: {
    position: 'absolute',
    right: 0,
    marginRight: 25,
    bottom: (props) => props.trialMode ? '25px' : '10px',
    textTransform: 'none',
  },
  notification: {
    width: '89%',
    fontSize: '12px',
    marginTop: '10px',
    backgroundColor: '#EEEAFB',
    color: '#542AD5',
    padding: '10px 15px',
  },
});

const MyComponent = ({ trialMode }) => {
  const classes = useStyles({ trialMode });

  return (
    <>
      <div className={classes.notification}>
        Trial Mode Active
      </div>
      <Button className={classes.button}>
        Investigate
      </Button>
    </>
  );
};
```

### After (Emotion) - Generated by Utility

```javascript
import React from 'react';
import { styled } from '@mui/material/styles';
import { Button, Box } from '@mui/material';

const NotificationBox = styled(Box)({
  width: '89%',
  fontSize: '12px',
  marginTop: '10px',
  backgroundColor: '#EEEAFB',
  color: '#542AD5',
  padding: '10px 15px',
});

const InvestigateButton = styled(Button)(({ trialMode }) => ({
  position: 'absolute',
  right: 0,
  marginRight: 25,
  bottom: trialMode ? '25px' : '10px',
  textTransform: 'none',
}));

const MyComponent = ({ trialMode }) => {
  return (
    <>
      <NotificationBox>
        Trial Mode Active
      </NotificationBox>
      <InvestigateButton trialMode={trialMode}>
        Investigate
      </InvestigateButton>
    </>
  );
};
```

**Changes:**
- ✅ Dynamic prop detection: `trialMode` identified
- ✅ Arrow function with destructured prop: `({ trialMode }) => ({...})`
- ✅ Props passed directly to styled component
- ✅ `notification` → `NotificationBox`
- ✅ `button` → `InvestigateButton` (semantic name)

## Example 3: Conditional Spread Styles

### Before (JSS)

```javascript
import React from 'react';
import { makeStyles } from '@mui/styles';
import { Typography } from '@mui/material';

const useStyles = makeStyles({
  action: {
    position: 'absolute',
    marginTop: (props) => props.padded ? '110px' : '35px',
    fontFamily: 'Roboto',
    fontSize: '12px',
    color: '#6A6A6A',
    ...(props) => props.padded && {
      display: '-webkit-box',
      WebkitBoxOrient: 'vertical',
      WebkitLineClamp: 2,
      overflow: 'hidden',
    },
  },
});

const MyComponent = ({ padded }) => {
  const classes = useStyles({ padded });

  return (
    <Typography className={classes.action}>
      Some action text
    </Typography>
  );
};
```

### After (Emotion) - Generated by Utility

```javascript
import React from 'react';
import { styled } from '@mui/material/styles';
import { Typography } from '@mui/material';

const CategoryAction = styled(Typography)(({ padded }) => ({
  position: 'absolute',
  marginTop: padded ? '110px' : '35px',
  fontFamily: 'Roboto',
  fontSize: '12px',
  color: '#6A6A6A',
  ...padded && {
    display: '-webkit-box',
    WebkitBoxOrient: 'vertical',
    WebkitLineClamp: 2,
    overflow: 'hidden',
  },
}));

const MyComponent = ({ padded }) => {
  return (
    <CategoryAction padded={padded}>
      Some action text
    </CategoryAction>
  );
};
```

**Changes:**
- ✅ Conditional spread preserved: `...padded && {...}`
- ✅ Single arrow function handles both conditional and spread
- ✅ `action` → `CategoryAction` (semantic name)

## Example 4: MUI Component with Nested Selectors

### Before (JSS)

```javascript
import React from 'react';
import { makeStyles } from '@mui/styles';
import { Tabs, Tab } from '@mui/material';

const useStyles = makeStyles({
  tabs: {
    minHeight: 'unset',
    '& .MuiTabs-indicator': {
      display: 'none',
    },
    '& .MuiTabs-scroller': {
      zIndex: 1,
      position: 'absolute',
      background: '#343434',
    },
  },
  tab: {
    background: '#FAFAFA',
    borderRight: '1px solid #202020',
    '&.Mui-selected': {
      background: '#FFF !important',
      color: '#1976d2 !important',
    },
  },
});

const MyComponent = () => {
  const classes = useStyles();

  return (
    <Tabs className={classes.tabs}>
      <Tab className={classes.tab} label="Tab 1" />
      <Tab className={classes.tab} label="Tab 2" />
    </Tabs>
  );
};
```

### After (Emotion) - Generated by Utility

```javascript
import React from 'react';
import { styled } from '@mui/material/styles';
import { Tabs, Tab } from '@mui/material';

const StyledTabs = styled(Tabs)({
  minHeight: 'unset',
  '& .MuiTabs-indicator': {
    display: 'none',
  },
  '& .MuiTabs-scroller': {
    zIndex: 1,
    position: 'absolute',
    background: '#343434',
  },
});

const StyledTab = styled(Tab)({
  background: '#FAFAFA',
  borderRight: '1px solid #202020',
  '&.Mui-selected': {
    background: '#FFF !important',
    color: '#1976d2 !important',

const MyComponent = () => {
  return (
    <StyledTabs>
      <StyledTab label="Tab 1" />
      <StyledTab label="Tab 2" />
    </StyledTabs>
  );
};
```

**Changes:**
- ✅ Nested selectors preserved
- ✅ Pseudo-class selectors preserved: `&.Mui-selected`
- ✅ MUI internal class overrides maintained
- ✅ `tabs` → `StyledTabs`, `tab` → `StyledTab`

## Example 5: Loading Icon

### Before (JSS)

```javascript
import React from 'react';
import { makeStyles } from '@mui/styles';
import { CircularProgress } from '@mui/material';

const useStyles = makeStyles({
  loading: {
    margin: '300px 50%',
  },
});

const MyComponent = ({ isLoading }) => {
  const classes = useStyles();

  return (
    <>
      {isLoading && (
        <CircularProgress
          className={classes.loading}
          disableShrink={true}
          size={35}
          thickness={3}
        />
      )}
    </>
  );
};
```

### After (Emotion) - Generated by Utility

```javascript
import React from 'react';
import { styled } from '@mui/material/styles';
import { CircularProgress } from '@mui/material';

const LoadingIcon = styled(CircularProgress)({
  margin: '300px 50%',
});

const MyComponent = ({ isLoading }) => {
  return (
    <>
      {isLoading && (
        <LoadingIcon
          disableShrink={true}
          size={35}
          thickness={3}
        />
      )}
    </>
  );
};
```

**Changes:**
- ✅ `loading` → `LoadingIcon` (semantic, indicates CircularProgress)
- ✅ Other props preserved
- ✅ Conditional rendering maintained

## Example 6: Multiple Classes with Different Base Components

### Before (JSS)

```javascript
import React from 'react';
import { makeStyles } from '@mui/styles';
import { Box, Typography, Button, Card } from '@mui/material';

const useStyles = makeStyles({
  container: {
    padding: '20px',
    backgroundColor: '#fff',
  },
  header: {
    marginBottom: '16px',
    fontWeight: 'bold',
  },
  card: {
    boxShadow: '0px 2px 4px rgba(0,0,0,0.1)',
  },
  button: {
    marginTop: '12px',
  },
});

const MyComponent = () => {
  const classes = useStyles();

  return (
    <Box className={classes.container}>
      <Typography className={classes.header}>
        Header
      </Typography>
      <Card className={classes.card}>
        Card Content
      </Card>
      <Button className={classes.button}>
        Action
      </Button>
    </Box>
  );
};
```

### After (Emotion) - Generated by Utility

```javascript
import React from 'react';
import { styled } from '@mui/material/styles';
import { Box, Typography, Button, Card } from '@mui/material';

const StyledBox = styled(Box)({
  padding: '20px',
  backgroundColor: '#fff',
});

const HeaderText = styled(Typography)({
  marginBottom: '16px',
  fontWeight: 'bold',
});

const StyledCard = styled(Card)({
  boxShadow: '0px 2px 4px rgba(0,0,0,0.1)',
});

const StyledButton = styled(Button)({
  marginTop: '12px',
});

const MyComponent = () => {
  return (
    <StyledBox>
      <HeaderText>
        Header
      </HeaderText>
      <StyledCard>
        Card Content
      </StyledCard>
      <StyledButton>
        Action
      </StyledButton>
    </StyledBox>
  );
};
```

**Changes:**
- ✅ Multiple styled components created
- ✅ Each uses appropriate base component
- ✅ Semantic names: `HeaderText`, `StyledCard`, `StyledButton`

## Key Improvements Summary

### 1. Naming
- **Old**: Generic names (Root, Container, Button)
- **New**: Semantic names (StyledBox, TitleText, LoadingIcon)

### 2. Element Types
- **Old**: HTML elements (div, span)
- **New**: MUI components (Box, Typography, CircularProgress)

### 3. Props Handling
- **Old**: Limited detection
- **New**: Automatic detection and proper destructuring

### 4. Code Quality
- **Old**: Manual JSX updates needed
- **New**: Fully automated JSX transformation

### 5. Maintainability
- **Old**: Generic component names
- **New**: Self-documenting component names

## Migration Tips

1. **Always run with `--dry-run` first** to preview changes
2. **Review generated names** - they should be semantic and clear
3. **Check dynamic props** - ensure they're properly detected
4. **Test visually** - verify styles apply correctly
5. **Run your test suite** - ensure functionality is preserved

## Next Steps

After migration:
1. Review the generated code
2. Run tests
3. Check for any remaining JSS imports
4. Consider cleanup with the cleanup command
5. Commit the changes
